# Output Template

## 1) Plain-English Historical Summary (Required)
- 150-260 words summarizing the leader/civilization and era.
- Focus on what made their rule/civilization distinctive.

## 2) Salient Historical Themes
- List 5-8 themes with source links.

## 3) History -> Mechanics Mapping (Required)
- For each theme, map to exact Civ4 concepts and proposed mechanics.
- Include rationale and tradeoff.

## 4) Baseline Audit (As-Is)
- Leader traits/personality/favorite civic-religion.
- Civ package (UU/UB/palace/replacements/defaults/city list/text/art hooks).
- Existing special improvements/build actions and caps.

## 5) Design Variants (2-3)
- Variant A/B/C with concise mechanical identity.
- Pick one recommendation and explain why.

## 6) Recommended Overhaul Spec (Implementation-Ready)
- Exact IDs and numeric values.
- Keep/modify/replace decisions for existing UU/UB.
- Improvement/build rules if present (tech/terrain/owner/cap/unit).
- Text keys to add/update.
- Art plan (workspace and optional external import path).

## 7) Distinctiveness Check
- Explain how this avoids repeating prior overhaul patterns.

## 8) Validation Plan
- XML schema checks, localization checks, in-game test cases.
