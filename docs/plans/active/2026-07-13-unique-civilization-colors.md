# Unique Civilization Colors

- Status: `implemented; visual validation pending`
- Owner / agent: GitHub Copilot CLI
- Last updated: `2026-07-14`

## Problem and approach

The 59 playable civilizations used only 35 default player colors, so 24
civilizations shared borders with another playable civilization. Keep the
first user of every existing color unchanged, append 24 new primary colors and
24 matching `PlayerColorInfo` records, and reassign only the duplicate users.
Flags, decals, and every pre-existing enum position remain unchanged.

Unique era-specific flags and the Native America/Apache/Polynesia ArtDefine
cross-wiring correction are a separate follow-up tracked in
[`2026-07-14-worker-civic-landmark-flag-followup.md`](2026-07-14-worker-civic-landmark-flag-followup.md).

The appended palette was selected by greedy maximum CIE Lab distance against
all existing primary colors and each previously selected addition. Every new
primary is at least 20 CIE76 units from that comparison set. This deliberately
varies lightness and saturation as well as hue instead of relying only on
red/green separation.

## Validation and acceptance

Automated contracts require 59 playable civilizations, 59 unique default
player-color references, 59 unique primary RGB triples, complete reference
resolution, exact append order, and minimum distance for every new primary.
Final acceptance remains a user-owned large-game world-map and minimap review,
including common color-vision deficiencies.
