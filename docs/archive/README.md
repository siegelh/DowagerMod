# Archive

This folder holds historical materials that are kept for context but should not be treated as current implementation truth.

## Layout

- `plans/` - superseded plans, implementation drafts, and saved design documents
- `debug/` - dated debugging notes and incident writeups
- `ideas/` - brainstorms and idea backlog documents

## Trust rule

- Archived docs are `Historical / verify before relying`.
- Use them for context only after checking live code, scripts, and current docs first.
