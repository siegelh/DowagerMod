# Historical Civilization Flag Pipeline

## Status and source of truth

This is the current operator and agent runbook for all 59 normal playable
civilization flags. The editable sources and canonical metadata live under
`tools/flags/`; the generated installer payload remains under the live BtS
assets root:

`CoreFiles/Sid Meier's Civilization IV Beyond the Sword/Beyond the Sword/Assets`

Do not edit base `Assets` or Warlords as compatibility copies. Do not point XML
at `tools/flags/` or any external/session path.

## The Civ4 fixed-color convention

Each live `CivilizationArtInfo` still references a DDS through `<Path>`.
`<bWhiteFlag>1</bWhiteFlag>` tells Civ4 to use its fixed-color flag path rather
than tinting an alpha-mask decal with the player's two team colors.

The non-obvious engine convention is:

- DXT3/BC2 RGB contains the complete historical artwork.
- Every encoded DXT3 alpha nibble is `0`, at every mip level.
- The file is 128x128 with eight mips and exactly 22,000 bytes.

This matches working Firaxis fixed-color flags. A conventional opaque-alpha
DXT3 file can render as a blank white or black cloth in game. Conversely, a
correct fixed-color file may look fully transparent in a normal image viewer;
inspect its RGB channels or use `build_review.py`.

Player colors are independent. Borders, city labels, minimap ownership,
scoreboard text, and unit indicators continue to use each civilization's
`DefaultPlayerColor`.

## Repository layout

- `tools/flags/manifest.json` — exact 59-record runtime mapping, active design,
  production digest, research, citations, provenance, and licensing.
- `tools/flags/designs/historical-v1/masters/` — approved 1024x1024 SVG/PNG
  masters. Do not overwrite this version when creating a future generation.
- `tools/flags/dxt3_fullcolor.py` — deterministic DXT3 encoder.
- `tools/flags/build_flags.py` — safe single, changed, all, and check builds.
- `tools/flags/build_review.py` — local scale/cloth gallery generator.
- `tools/flags/history/original-team-color.json` — original-design recovery
  inventory.
- `tmp/flags/` — generated logs/review output; ignored by Git.

Install the tool-only Python dependencies if the current environment lacks
them:

```powershell
python -m pip install -r .\tools\flags\requirements.txt
```

## Updating one flag

1. Replace only that civilization's master in
   `tools/flags/designs/historical-v1/masters/`, or create a new versioned
   design directory and update its manifest record.
2. Update the record's provenance, licensing, design notes, master SHA-256, and
   expected production DDS SHA-256.
3. Generate and inspect the local gallery:

   ```powershell
   python .\tools\flags\build_review.py
   ```

   Open `tmp\flags\review\index.html` and inspect 128/64/32/16 readability and
   the cloth approximation.
4. Build the one runtime target:

   ```powershell
   python .\tools\flags\build_flags.py --civilization CIVILIZATION_FRANCE_BOURBON
   ```

5. Run the focused tests and repository gate.
6. Reinstall the mod and smoke-test in Civ4. The game renderer is authoritative.

The builder derives and validates the civilization-to-art-to-path chain from
the live XML. It refuses duplicates, remaps, unsafe paths, missing masters,
master-digest drift, output-digest drift, and unexpected playable entries.

## Rebuild and deterministic check

```powershell
python .\tools\flags\build_flags.py --changed
python .\tools\flags\build_flags.py --all
python .\tools\flags\build_flags.py --check
```

`--changed` uses master/manifest changes relative to `HEAD`. `--all` writes the
exact 59 runtime files and idempotently enables fixed-color mode for those art
definitions. `--check` writes only to temporary storage, compares every
generated byte with the manifest and live DDS, and requires all 59 live
`bWhiteFlag` values to be `1`.

Non-check builds validate every selected result before publishing any runtime
file. DDS replacements and the XML update are transactional: if publication
fails, the tool restores the pre-build DDS and XML bytes.

Every batch emits structured per-flag progress and a final reconciliation with
expected, processed, persisted, skipped, duplicate, error, byte, duration, and
retry totals. The default JSONL log is `tmp/flags/build-log.jsonl`.

## Licensing and attribution

Before committing a changed master:

1. Confirm the source may be redistributed and adapted.
2. Update `source_page_url`, `source_license`, `attribution`,
   `licensing_note`, and `reference_assets` in `manifest.json`.
3. Update `tools/flags/attribution.md`.
4. Keep CC BY-SA derivatives under the stated compatible ShareAlike terms and
   preserve creator/source/license attribution.
5. Do not commit reference-only photographs or copyrighted modern commercial
   renderings.

Historical facts and public-domain heraldry do not automatically make a modern
illustration public domain. The manifest distinguishes procedural redraws,
public-domain assets, and attributed ShareAlike derivatives.

## Original Firaxis/team-color designs

The original generation is preserved as history, not duplicated as a second
runtime tree. The pre-full-color baseline is:

`178f61f52a0ff96d86830d92e03d7967e655d9d0`

`tools/flags/history/original-team-color.json` records:

- 38 originals recoverable directly from that commit;
- five additional loose equivalents in the Warlords mirror;
- 16 stock packed assets that were never loose in this repository.

Recover one tracked original without changing the branch:

```powershell
git show 178f61f52a0ff96d86830d92e03d7967e655d9d0:"<repository path>" > original.dds
```

To return the entire branch to the original generation, revert the production
adoption commit. On an installed machine, the installer can also restore the
per-machine pristine game snapshot. Do not fabricate the 16 packed stock
binaries from similarly named art.

## Troubleshooting

| Symptom | Likely cause | Action |
|---|---|---|
| White or black blank cloth | Opaque/nonzero DXT3 alpha | Rebuild with `FIXED_COLOR_ZERO`; run `--check`. |
| Viewer shows transparency | Normal viewers honor zero alpha | Use `build_review.py` or inspect RGB channels. |
| Old flags remain after install | Stale Civ4 XML/art cache | Re-run the installer and confirm `DisableCaching = 1`. |
| Wrong civilization receives art | Manifest/XML mapping drift | Do not bypass reconciliation; correct the mapping source. |
| Missing original stock DDS | Asset was packed, not loose | Revert the production commit or restore the pristine install. |
